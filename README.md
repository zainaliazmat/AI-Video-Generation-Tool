# Faceless Video Generator

A **local, near-zero-cost faceless short-form video generator**. Give it a topic
and it produces a vertical **1080×1920** narrated video with stock footage, Ken
Burns motion, and animated word-by-word captions. Everything runs on your own
machine — no paid SaaS in the default path.

```
  TOPIC
    │
    ▼
┌─────────────────────────────┐        ┌──────────────────────────────┐
│  BACKEND  (Python)          │        │  RENDERER  (Remotion / TS)    │
│  the "what to show" brain   │ spec   │  the "how it looks" engine    │
│                             │ .json  │                               │
│  1. Script  (LLM)           │ ─────▶ │  • Player preview app         │
│  2. Voice   (Kokoro TTS)    │  +     │    (@remotion/player)         │
│  3. Timing  (faster-whisper)│ assets │  • <Video> composition        │
│  4. Footage (Pexels API)    │ ─────▶ │  • render → out/video.mp4     │
│  5. Assemble spec.json      │        │                               │
└─────────────────────────────┘        └──────────────────────────────┘
```

The **`spec.json` file is the only contract** between the two halves. The backend
never renders; Remotion never makes network/AI calls. Either side can be rebuilt
independently as long as the spec keeps its shape.

## Project layout

| Path | What it is |
|------|------------|
| `backend/` | Python pipeline: `main.py` orchestrator + `pipeline/` stages (`script`, `tts`, `timing`, `footage`, `assemble`). Import root — run modules from here. |
| `backend/schema.py` | Pydantic models for the `spec.json` contract. |
| `remotion/` | Remotion 4.x renderer. Reads `spec.json`, renders `out/video.mp4`. |
| `preview/` | Next.js 15 studio UI with `@remotion/player`: enter a topic, watch the pipeline run, preview live, render the MP4. |
| `sample-spec.json` | A hand-written example spec for working on the renderer/preview without running the backend. |
| `spec.json` | Generated by the backend (gitignored). The live contract the renderer/preview read. |
| `.env.example` | Template for required env vars — copy to `.env`. |

## Prerequisites

- **Python 3.12** (backend)
- **Node 22** (renderer + preview)
- **ffmpeg** (used by Kokoro/whisper and Remotion)
- A **Pexels API key** (free at <https://pexels.com/api>) for the footage stage
- An LLM provider key — **DeepSeek** by default (`DEEPSEEK_API_KEY`); `anthropic`
  and local `ollama` are pluggable alternatives via `LLM_PROVIDER`.

> First backend run downloads model weights (Kokoro ~82M, faster-whisper `base`
> ~150 MB) and spaCy `en_core_web_sm`. A full CPU-only generation takes ~2.5 min.

## Setup

```bash
# 1. Secrets
cp .env.example .env        # then fill in DEEPSEEK_API_KEY and PEXELS_API_KEY

# 2. Backend (Python)
python3.12 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt

# 3. Renderer + preview (Node)
( cd templates && npm install )   # required first: remotion's typecheck reaches into ../templates (zod lives there)
( cd remotion  && npm install )
( cd preview   && npm install )
```

> **Setup constraints worth knowing:**
> - The preview app spawns the backend via `backend/.venv/bin/python` (hardcoded
>   in `preview/app/api/_spawn.ts`) — create the venv at exactly that path or the
>   API routes 500.
> - `next build` fetches DM Sans/DM Mono from Google Fonts at build time
>   (`next/font`) — offline/air-gapped builds fail; `npm run dev` and typecheck
>   are unaffected.

## Usage

### Generate a video (full pipeline)

Run from the **repo root** — the backend writes `spec.json` here and assets into
`remotion/public/assets/`:

```bash
backend/.venv/bin/python backend/main.py --topic "3 facts about deep sea creatures"
```

| Flag | Default | Purpose |
|------|---------|---------|
| `--topic` | *(required)* | What the video is about. |
| `--fps` | 30 | Frames per second. |
| `--progress-json` | off | Emit machine-readable `PROGRESS {…}` lines per stage (used by the preview's SSE). |

### Preview in the browser (recommended)

The Next.js studio drives the whole flow — enter a topic, watch the 5-stage
pipeline, preview the result, and render the MP4:

```bash
cd preview && npm run dev      # http://localhost:3000
```

Generating from the UI runs the backend for you and swaps the player to the new
video when it finishes.

### Render the final MP4

```bash
cd remotion && npm run render  # → remotion/out/video.mp4
```

Other renderer scripts: `npm run studio` (Remotion Studio), `npm run bundle`.

## How the spec flows

The backend writes `spec.json` at the repo root. Both the renderer and the
preview stage it into their own `public/` via copy scripts
(`remotion/scripts/copy-spec.mjs`, `preview/scripts/copy-assets.mjs`). Resolution
precedence is `SPEC_PATH` → root `spec.json` → `sample-spec.json` fallback, so the
renderer/preview always have something valid to show.

## Configuration

All config lives in `.env` (loaded by the backend via `python-dotenv`). See
[`.env.example`](.env.example) for the full annotated list. Key variables:

- `LLM_PROVIDER` — `deepseek` (default) · `anthropic` · `ollama`
- `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` — `deepseek-v4-flash` (default) or `deepseek-v4-pro`
- `PEXELS_API_KEY` — required for the footage stage
- `TTS_VOICE` — Kokoro voice (default `af_heart`)
- `SPEC_PATH` — override the spec output/input path

## Testing

Pure logic (frame math, parsing, alias serialization) is unit-tested with
dependency-injected fakes — no network or model downloads:

```bash
backend/.venv/bin/python -m pytest backend/tests
```

Each network/model-backed stage also has a live smoke test.
